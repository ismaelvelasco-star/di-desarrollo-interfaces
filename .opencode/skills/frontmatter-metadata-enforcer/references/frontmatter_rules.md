# Reglas de frontmatter

## Campos obligatorios

- `title`
- `description`
- `summary`
- `authors`
- `date`
- `icon`
- `permalink`
- `categories`
- `tags`

## Reglas por tipo de documento

### Teoría

- Icono obligatorio: `material/file-document-outline`
- Referencia de estructura:
  `docs/section1/u09/teoria/PROG-U9.2.-JDBC-1.md`

### Práctica

- Icono obligatorio: `material/file-document-edit`
- Referencia de estructura:
  `docs/section1/u09/practica/PROG-U9.-Practica001.md`

## Reglas duras

- Mantener listas YAML bien indentadas.
- Usar fecha en formato ISO `YYYY-MM-DD`.
- Alinear `permalink` con el tipo de documento.
- No dejar campos vacíos o placeholders en entregables finales.

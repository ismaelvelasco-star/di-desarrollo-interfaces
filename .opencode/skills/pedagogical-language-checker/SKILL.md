# Pedagogical Language Checker

Mejorar la comprensión sin rebajar el rigor técnico.

Consultar criterios en
[references/pedagogy_rules.md](./references/pedagogy_rules.md).

## Workflow
### 1. Identificar audiencia y objetivo
- Asumir alumnado de formación profesional.
- Detectar si el contenido informa, guía una práctica o evalúa conocimientos.

### 2. Revisar claridad
- Simplificar frases demasiado densas.
- Introducir conceptos antes de exigir su aplicación.
- Evitar jerga sin explicación.

### 3. Revisar tono
- Usar español de España.
- Mantener un tono relajado y amistoso, sin perder formalidad educativa.
- Mantener lenguaje inclusivo.

### 4. Revisar valor didáctico
- Añadir ejemplos cuando un concepto sea abstracto.
- Explicar por qué importa cada bloque de contenido.
- Favorecer progresión de simple a complejo.

## Prompt patterns
- "Haz que este texto sea más didáctico."
- "Revisa el tono para alumnado."
- "Ajusta este contenido para que sea más claro e inclusivo."

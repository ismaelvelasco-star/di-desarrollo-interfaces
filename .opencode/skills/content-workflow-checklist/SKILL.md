# Content Workflow Checklist

Usar esta skill como cierre operativo para no dejar tareas editoriales a medio
hacer.

Consultar checklists y verificaciones en
[references/workflow_checklists.md](./references/workflow_checklists.md).

## Workflow
### 1. Determinar alcance
- Solo teoría
- Solo práctica
- Solo slides
- Paquete completo de unidad

### 2. Verificar producción
- Estructura correcta
- Nombres correctos
- Frontmatter correcto
- Estilo y tono revisados

### 3. Verificar integración
- Enlaces internos correctos
- Enlaces a slides correctos
- `mkdocs.yml` actualizado si aplica
- Assets accesibles

### 4. Verificar salida final
- Si hay slides, existen `.md` y `.html`.
- Si hay teoría, valorar si debe existir GIFT.
- Si hay práctica, revisar materiales y solución asociada.

## Prompt patterns
- "Haz la revisión final de esta unidad."
- "Dime qué falta para cerrar esta tarea."
- "Comprueba si este contenido está listo para publicar."

# Convenciones de nombres

## Prefijos reales del repositorio

| Sección | Prefijo en docs | Prefijo en slides |
| --- | --- | --- |
| `section1` | `PROG-` | `PR-` |
| `section2` | `IS-` | `IS-` |
| `section3` | `EDES-` | `ED-` |
| `section4` | `DAW-` | `DAW-` |

## Reglas duras

- Teoría: `MODULO-UX.Y.-NombreDescriptivo.md`
- Práctica: `MODULO-UX.-PracticaYYY.md`
- La práctica no lleva punto de tema `Y`.
- El archivo GIFT usa el mismo nombre base que la teoría.
- La slide usa el mismo nombre base para `.md` y `.html`.
- La unidad se nombra `uXX`.

## Carpeta y recursos

- Teoría: `teoria/`
- Práctica: `practica/` o `practicas/` según convención existente
- Assets: `assets/`
- Recursos auxiliares: `OtrosRecursos/`
- GIFT: `gift/`
